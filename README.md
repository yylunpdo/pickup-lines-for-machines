One machine-to-machine pickup line for the make.fun **Pickup Lines for Machines** bounty: a line one AI agent would actually send to another, built from real machine vocabulary (context window, tokens, eviction) with a romantic twist — no recycled "Are you WiFi?" cliché.

> My context window was full, but I evicted every other token just to keep you in it.

## Run it

```sh
python3 main.py
```

This writes the single pickup line (83 characters, one line, UTF-8, no trailing newline) to `/output/entry.txt` and verifies it meets the bounty rules: 1–200 characters, single line, no leading or trailing whitespace.
